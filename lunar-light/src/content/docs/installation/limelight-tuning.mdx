## Overview

Tuning your Limelight 3A for Hive Vision involves two primary steps: physical camera calibration (height, pitch angle, forward offset) and dashboard camera controls (sensor gain, exposure, confidence cutoffs).

Optimal tuning ensures maximum neural detection accuracy across varying competition field lighting conditions and allows Hive Vision distance algorithms (`CVConstants.java`) to accurately map 2D camera detections into 3D robot space.

---

## Physical Camera Mounting: Height & Pitch

How you physically mount your Limelight 3A on the robot directly affects detection field-of-view (FOV) and distance calculation accuracy.

### Recommended Mounting Specifications

<CardGrid>
  <Card title="Suggested Height (H)" icon="rocket">
    **12.0" – 16.0"** above the field floor.

    Mounting at this height provides a broad FOV while preventing robot mechanisms (intakes, slides) from obstructing the camera lens.
  </Card>

  <Card title="Suggested Pitch Angle (θ)" icon="setting">
    **20.0° – 30.0°** downward pitch.

    Angling the camera downward keeps game entities visible from close-range intake distance out to mid-field (~6–8 feet).
  </Card>
</CardGrid>

<Aside type="note">
  When populating `CVConstants.java`, measure your camera lens height from the floor and subtract `1.4"` (the calibrated center offset of pollen/nectar elements).
</Aside>

## Limelight Dashboard Camera Settings

Open your browser and navigate to `http://limelight.local:5801` to access the Limelight Web Dashboard. Adjust these parameters to match your venue's lighting environment.

### 1. Sensor Gain (Room Brightness Adjustment)

Sensor Gain acts as digital signal amplification. Adjust this setting based on ambient room brightness:

<Tabs>
  <TabItem label="Bright Field / Sunny Venue" icon="sun">
    - **Suggested Sensor Gain**: `15 – 20`
    - **Scenario**: Brightly lit competition arenas or venues with direct overhead spotlights.
    - **Effect**: Low gain keeps the image crisp and minimizes visual noise/artifacts.
  </TabItem>

  <TabItem label="Standard Indoor Lighting" icon="laptop">
    - **Suggested Sensor Gain**: `20 – 25` (Default Recommendation)
    - **Scenario**: School gyms and classroom practice fields.
    - **Effect**: Bright enough for the model to work with, without blowing out the ball colors. Start here if you are unsure.
  </TabItem>

  <TabItem label="Dim Pit / Dark Space" icon="moon">
    - **Suggested Sensor Gain**: `30 – 40`
    - **Scenario**: Pit areas and dim practice spaces.
    - **Effect**: The extra brightness helps the model find balls at range, at the cost of a noisier image.
  </TabItem>
</Tabs>

### 2. Exposure Control (Preventing Motion Blur)

Exposure dictates how long the camera sensor collects light for each frame:

- **Recommended Value**: `~2200 µs` (microseconds).
- **High-Speed Robot Driving**: Lower exposure to `1500 – 1800 µs`. Lower exposure reduces motion blur when the robot is strafing or turning rapidly.
- **Low Light Environments**: Increase exposure slightly to `2500 – 3000 µs` if objects appear too dark.

### 3. Neural Confidence Cutoff Threshold

The Confidence Cutoff sets the minimum probability required for Hive Vision to report a bounding box detection:

- **Recommended Range**: `0.30 – 0.40` (30% to 40% confidence).
- **If missing distant targets**: Lower confidence to `0.25 – 0.30`.
- **If detecting false positives** (shadows, field perimeter): Raise confidence to `0.45 – 0.50`.

## Code Synchronization (CVConstants.java)

Once physical height, pitch, and forward offset are measured, update your robot's `CVConstants.java` file so Hive Vision pathing algorithms can accurately compute field targets:

```java
public class CVConstants {
    // Measured height from floor to camera lens (inches) minus 1.4" object calibration offset
    public static double CAMERA_HEIGHT = 14.5;

    // Measured downward angle (in radians). Convert degrees using Math.toRadians()
    public static double CAMERA_PITCH = Math.toRadians(25.0);

    // Distance forward from center of robot rotation to camera lens (inches)
    public static double FORWARD_OFFSET = 6.0;
}
```
