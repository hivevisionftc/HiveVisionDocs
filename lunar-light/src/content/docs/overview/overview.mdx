**Hive Vision** is an optimized, easy-to-use computer vision framework engineered specifically for **FIRST Tech Challenge (FTC)** teams. Built from the ground up by student developers, Hive Vision empowers robots with competitive neural object detection, real-time color thresholding, target auto-alignment, and dynamic spline path generation.

Whether you're running hardware-accelerated deep neural networks on co-processors or native HSV color tracking on the FTC Control Hub, Hive Vision provides a seamless bridge between raw camera feeds and autonomous trajectory execution.

## Complete Core Capabilities

Hive Vision comes packed with features designed to solve the toughest computer vision and autonomous pathing challenges in FTC.

### 1. Dual Vision Processing Architecture

Hive Vision supports two distinct hardware pathways depending on your team's budget, hardware availability, and processing requirements:

<Tabs>
  <TabItem label="Limelight 3A (Coprocessor AI)" icon="cpu">
    - **Zero Control Hub Load**: Neural inference runs entirely on the Limelight 3A's internal CPU/NPU coprocessor.
    - **MobileNet V2 SSD Model**: Pre-trained model (`best_limelight3a_ssd_mobilenetv2_300x300_v2_int8_dets25.tflite`) recognizing yellow pollen, red nectar, and blue nectar.
    - **High Resolution & Frame Rate**: Maintains crisp detection without causing loop-time lag in robot TeleOp or Autonomous code.
    - **Custom Thresholding & Gain Control**: Fine-tune sensor gain (~20), exposure (~2200), and confidence cutoffs (0.3–0.4) right from the Limelight Web UI.
  </TabItem>

  <TabItem label="Control Hub Webcam (OpenCV HSV)" icon="camera">
    - **Zero Extra Hardware Required**: Runs directly on standard USB webcams connected to the REV Control Hub.
    - **VisionPortal Processor**: Plugs directly into `org.firstinspires.ftc.vision.VisionPortal` using `BallDetectorPipeline`.
    - **Normalized Coordinates**: Calculates normalized center coordinates (`cxNorm`, `cyNorm`) between `0.0` and `1.0` across the screen frame.
    - **Color Gate Filtering**: Instant color queries via `baller.bestOf(BallColor.RED)`, `BLUE`, or `YELLOW`.
  </TabItem>
</Tabs>

---

### 2. Physical 3D Spatial Calculation & Offsets

Transforming 2D camera pixels into physical 3D robot target coordinates requires accounting for camera mounting geometry. Hive Vision standardizes physical offsets so you can accurately measure distance to detected entities:

```java
public class CVConstants {
    // Camera lens height above the field floor (inches) minus 1.4 inch object calibration offset
    public static double CAMERA_HEIGHT = 14.5;

    // Downward camera pitch angle (0.0 = pointing level parallel to ground)
    public static double CAMERA_PITCH = Math.toRadians(25.0);

    // Distance from the robot's center of rotation to the camera lens (inches)
    public static double FORWARD_OFFSET = 6.0;
}
```

### 3. PedroPathing Autonomous Trajectory Generation

Hive Vision integrates seamlessly with **PedroPathing** for automated spline trajectory generation (`CVPathGen` and `CVCostAlgo`).

<Steps>
1. **Target Identification**: Neural network or color detector identifies target entities in the field of view.
2. **Cost Evaluation (`CVCostAlgo`)**: Evaluates entity positions relative to the robot heading, selecting targets that minimize drive time and turning angle.
3. **Bezier Curve Construction (`CVPathGen`)**: Constructs continuous Bezier splines connecting the current robot pose to the target location.
4. **Automated Spline Execution**: Driver presses `gamepad1.a` to trigger smooth spline navigation through detected pollen and nectar.
</Steps>

---

### 4. TeleOp Auto-Chase & Color Selector

Hive Vision isn't just for Autonomous—it provides critical driver assistance during TeleOp matches:

- **Filter Selection on the Fly**:
  - `D-pad UP`: Selects **RED** entities only.
  - `D-pad DOWN`: Selects **BLUE** entities only.
  - `D-pad LEFT`: Selects **RED + BLUE** entities.
  - `D-pad RIGHT`: Selects **ALL** colors (RED, BLUE, and YELLOW).
- **One-Button Auto-Chase (`Right Bumper`)**:
  - Pressing **RB** toggles Auto-Chase mode. The drivetrain automatically turns toward and approaches the target object.
  - Full manual override is restored when Auto-Chase is toggled off.

## Architecture Comparison

| Feature | Limelight 3A Pipeline | Control Hub Webcam Pipeline |
| :--- | :--- | :--- |
| **Detection Method** | SSD MobileNet V2 Neural Net (`.tflite`) | OpenCV HSV Color Thresholding (`BallDetectorPipeline`) |
| **Processing Host** | Limelight 3A Internal Processor | REV Control Hub CPU |
| **FTC SDK Impact** | 0% CPU Overhead on Control Hub | Minimal (VisionPortal Threading) |
| **Object Recognition** | Entity Shape + Class Labeling | Color-Based Blob Detection |
| **Setup Complexity** | Web Dashboard Upload | Drop-in `.java` TeamCode Files |
| **Recommended Use** | Competitive Matches & Autonomous | Budget-Friendly & Rapid Prototyping |

## Library Code Examples

Here is how simple it is to integrate Hive Vision into your FTC code base:

<Tabs>
  <TabItem label="VisionPortal Setup (Webcam)" icon="code">
```java
import org.firstinspires.ftc.vision.VisionPortal;
import org.firstinspires.ftc.robotcore.external.hardware.camera.WebcamName;
import org.opencv.core.Size;

// Instantiate the Hive Vision BallDetectorPipeline
BallDetectorPipeline baller = new BallDetectorPipeline();

// Register with FTC VisionPortal
VisionPortal portal = new VisionPortal.Builder()
        .setCamera(hardwareMap.get(WebcamName.class, "Webcam 1"))
        .setCameraResolution(new Size(1280, 720))
        .addProcessor(baller)
        .enableLiveView(true)
        .build();
```
  </TabItem>

  <TabItem label="Telemetry & Coordinate Query" icon="document">
```java
// Query highest-confidence RED target
BallDetectorPipeline.BallBlob red = baller.bestOf(BallDetectorPipeline.BallColor.RED);

if (red != null) {
    // cxNorm and cyNorm return screen relative coordinates from 0.0 to 1.0
    telemetry.addData("RED Target Found", "cx=%.2f cy=%.2f", red.cxNorm, red.cyNorm);
} else {
    telemetry.addData("RED Target", "None detected");
}
```
  </TabItem>

  <TabItem label="Limelight Pipeline Query" icon="terminal">
```java
// Querying Limelight 3A neural network pipeline outputs
LLResult result = limelight.getLatestResult();
if (result != null && result.isValid()) {
    List<LLResultTypes.DetectorResult> detections = result.getDetectorResults();
    for (LLResultTypes.DetectorResult detection : detections) {
        String className = detection.getClassName(); // "yellow_pollen", "red_nectar", etc.
        double confidence = detection.getConfidence();
        double[] targetPose = detection.getTargetPoseRobotSpace();
    }
}
```
  </TabItem>
