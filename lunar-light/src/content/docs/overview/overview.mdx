**Hive Vision** is a computer vision package for FIRST Tech Challenge (FTC) robots. It detects game pieces — yellow pollen, blue nectar, and red nectar — and reports their position in the camera view. It can be integrated with your camera of choice. Currently Hive Vision supports:

- <Badge text="Limelight 3A" variant="note" />
- <Badge text="Webcam" variant="caution" />

## What it detects

Hive Vision labels each game piece it sees as `yellow_pollen`, `blue_nectar`, or `red_nectar`. On the Limelight 3A, each detection also includes a confidence score. You can use these results to drive toward a piece, line up with it, or decide what to pick up next.

## Choose your camera

Both options give you detection. They differ in where the processing runs and how they are set up.

|  | Limelight 3A | Webcam |
| --- | --- | --- |
| **Detection** | Neural network | HSV color thresholding |
| **Runs on** | Limelight's own processor | Control Hub |
| **Extra hardware** | Limelight 3A | Webcam |
| **Confidence scores** | Yes | No |
| **Best for** | Keeping vision off your robot code | Teams that already have a webcam |

### Limelight 3A

Hive Vision supports the Limelight 3A with an all-inclusive neural network package that you add to your pipeline to start tracking. The Limelight runs the detector on its own processor, so detection is unaffected by the FTC SDK and your robot code keeps its own resources. The model was trained on about 14,000 labeled images.

[Install for Limelight 3A →](/installation/limelight)

### Webcam

Hive Vision also offers a full package for HSV color detection on a webcam connected to your Control Hub. It uses color thresholding rather than a trained model, so it needs no model and no extra hardware beyond the webcam. Detection runs on the Control Hub itself, alongside your robot code.

[Install for Webcam →](/installation/webcam)
